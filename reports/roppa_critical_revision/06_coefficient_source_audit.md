# 06. Table 3과 Table 4 계수 출처 최종 감사

## 최종 결론

Table 3과 Table 4의 숫자는 표준화계수 β가 아니라 대부분 **합성점수 OLS의 비표준화계수 B**이다. 또한 현재 원고 표는 현재 저장된 수정 코드의 출력이 아니라, 성별을 문자열로 잘못 비교하고 출생연도를 그대로 투입했던 구버전 실행 결과를 사용했다. Table 4는 여기에 Model 4의 윤리적 리더십 계수를 Model 3 표에 추가해 모형이 혼입됐다.

기존 OLS 주분석을 유지하면서 해결할 수 있다. 가장 작은 일관된 수정은 다음과 같다.

1. Table 3은 현재 수정된 `05_regression_upb.py`의 Model 1~4 출력으로 교체하고 계수 머리글을 B로 쓴다.
2. Table 4는 현재 수정된 Model 3 결과를 사용하고 EL 행을 삭제한다.
3. 본문의 β를 B로 바꾸되, 구버전과 현재 결과가 다른 값은 현재 B와 p로 교체한다.

## 구버전 분석의 두 가지 오류

### 성별 인코딩

구버전은 `SQ1K1 == "남자"`를 사용했지만 전처리 자료의 값은 1.0/2.0이었다. 따라서 `gender_male`이 전부 0인 상수가 됐다. 이 상태의 성별 계수·표준오차·p값은 해석할 수 없다. 현재 코드는 `SQ1K1 == 1.0`으로 수정됐다.

### 출생연도와 연령

구버전 Model 1~4는 `SQ1K2_1` 출생연도를 그대로 투입하면서 표에서는 “연령”으로 표시했다. 그래서 Table 3의 양수 .002/.004/.007/.007은 연령효과가 아니라 출생연도 B다. 현재 코드는 `age = 2023 - SQ1K2_1`을 사용하므로 같은 관계의 부호가 음수로 바뀐다. 다른 예측변수의 계수는 성별 수정 때문에 소폭 달라졌다.

## Table 4 출처 판정

Table 4의 여섯 DEI/OI 셀은 구버전 Model 3에서 왔다.

- UPB: Equity .194, Inclusion -.032, OI .150
- OCB: Equity -.047, Inclusion .282, OI .217

UPB EL=.017은 구버전 UPB Model 4의 `ethical_leadership` B=.0170(SE=.028, p=.543)이다. OCB EL=.063 역시 구버전 OCB Model 4의 B=.0633(SE=.023, p=.006)이다. 따라서 EL 행 전체가 Model 3 표에 혼입됐다.

## EL=.017의 정확한 출처와 최소 수정

- 원래 모형: UPB Model 4
- 변수 구성: 성별 + 출생연도(구버전) + 공공부문 + Equity + Inclusion + OI + EL
- 구버전 출력: B=.0170, SE=.028, p=.543, 파생 β=.020
- 현재 수정 출력: B=.0175, SE=.028, p=.532, 파생 β=.021
- Model 3에는 EL이 포함되지 않는다.

가장 작은 수정은 Table 4가 이미 “Model 3 기준, EL 제외”라고 명시하므로 **EL 행을 삭제하는 것**이다. EL을 유지하려면 UPB와 OCB의 모든 행을 Model 4 계수로 바꾸고 R²도 .095/.228로 바꿔야 하므로 수정 범위가 더 크다.

## 기존 04 보고서의 검증

`04_statistical_reporting_consistency_audit.md`의 “B를 β로 표기”, “Table 4 모형 혼입” 지적은 확인됐다. 다만 최종 감사에서 두 가지를 더 구체화했다.

1. Table 3과 Table 4의 다수 수치는 단순 표기 오류가 아니라 성별 인코딩 오류가 있던 구버전 출력이다.

따라서 일부 셀은 B/β 기호만 바꾸면 되지만, Table 3 연령·현재 코드와 달라진 셀·Table 4 OCB 열·EL 관련 값은 수치 자체를 교체해야 한다.
