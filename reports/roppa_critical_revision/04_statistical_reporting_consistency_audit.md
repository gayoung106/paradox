# 04. 통계 보고 및 추론 일관성 감사

## 결론

기존 분석 자체는 재현 가능하고 핵심 방향은 대체로 안정적이지만, 현재 원고에는 **B를 β로 표기한 오류, 서로 다른 모형의 계수 혼합, Wald p와 bootstrap CI의 선택적 사용 가능성, 가설 번호 불일치**가 남아 있다. 이는 제출 전 반드시 고쳐야 한다. 추론 기준은 잠재 SEM의 직접효과·대비·간접효과·상호작용에 대해 사전 지정된 bootstrap CI를 우선하고, HC3 OLS는 강건성 자료로 일관되게 분리하는 방식을 권고한다.

## 사용된 추론방법과 적절한 용도

| 방법 | 기존 사용처 | 권장 역할 |
|---|---|---|
| HC3 robust SE | 합성점수 위계회귀, 직접효과, 조절 | 보충 강건성; B/진짜 표준화 β를 명확히 구분 |
| SEM Wald z/p | 잠재 구조경로의 기본 출력 | 점추정 설명용; 비정규·경계 결과는 bootstrap과 함께 해석 |
| Percentile bootstrap CI | 초기 H4 경로·대비, 일부 매개 | BCa가 없는 경우 명시적으로 사용 |
| Bias-corrected(BC) CI | 합성점수 동시매개, 간접효과 비교 | 해당 합성점수 분석의 정본 CI |
| BCa CI | 잠재 H4, 동시매개, H7 PI | 잠재 SEM 핵심 추론의 우선 기준 |

CI 종류를 모두 “bootstrap CI”로 뭉뚱그리지 말고 percentile, BC, BCa를 표 주석에 각각 표시해야 한다.

## Inclusion→UPB 불일치 사례

통합 잠재 SEM의 Inclusion→UPB 경로는 β=-.097이다.

- Wald p=.0239: 정규근사 기준 유의
- 2,000회 percentile CI [-.192,-.002]: 0 미포함
- 2,000회 BCa CI [-.190,.003]: 0 포함

BCa 보정 후 상한이 0을 아주 작게 넘는다. Equity–Inclusion의 높은 잠재상관(r=.729)과 억제 패턴 때문에 표집분포가 Wald 정규근사와 정확히 일치하지 않은 것으로 해석할 수 있다. 사후적으로 원하는 결론을 선택하지 않기 위해, 잠재 SEM 핵심효과에 BCa를 사용하기로 한 전체 기준을 이 경로에도 적용한다. 따라서 이 경로는 **경계적이며 주분석 기준 비유의**로 보고하고, 보호효과라는 새 주장을 만들지 않는다.

## 계수·표·본문 감사

### CRITICAL 오류

1. `output/final/final_manuscript.md` Table 4는 “Model 3, EL 제외”라고 쓰면서 EL=.017을 같은 표에 넣었다. 기존 감사에서 이는 Model 3의 형평·포용·OI 계수에 Model 4의 EL 계수를 붙인 모형 혼입으로 확인됐다. EL 행을 제거하거나 모든 계수를 동일 Model 4에서 다시 제시해야 한다.
2. 원고의 Table 3·4는 `.194`, `.150`, `.281` 등을 β로 서술하지만 정본 출력 `results/tables/table5_dei_oi_direct_effects.csv`는 **비표준화 B(HC3 SE)**다. 예를 들어 동일 모형의 실제 표준화 계수는 UPB에서 Equity β=.216, OI β=.144, OCBI에서 Inclusion β=.331, OI β=.245다. 표와 본문의 기호를 B로 바꾸거나 진짜 β로 표 전체를 교체해야 한다.
3. 원고 H1/H2·매개 표는 개별 단순매개의 B(.393, .429, .048, .078)를 통합모형의 β·주결과처럼 사용한다. 통합 동시 SEM의 H1/H2는 β=.286/.317이고 동시 간접효과는 .052/.058이다. 서로 다른 모형의 수치를 한 가설 체계에서 혼용하면 안 된다.
4. 현재 원고는 H1~H6, SEM 결과 파일은 조절가설을 H7로 부른다. 번호와 가설 문구를 제출본 전체에서 하나로 통일해야 한다.

### IMPORTANT 오류·과장

- 원고는 높은 EL에서도 조건부 효과가 유의하다는 OLS 결과를 본문에 쓴다. PI 주분석에서는 높은 EL의 OI→UPB=.084, BCa [-.012,.188]이며 조건부 간접효과도 0을 포함한다.
- “포용 매개비율 47% 대 형평 20%”로 메커니즘 강도 차이를 주장하지만 동시모형 간접효과 차이는 유의하지 않다.
- “윤리적 리더십이 상호작용을 통해서만 영향을 준다”는 표현은 직접효과 비유의에서 너무 강한 결론이다. 이 자료에서 직접효과를 확인하지 못했다고만 써야 한다.
- EFA/CFA가 두 요인을 구분한다는 것은 구성개념 구분의 근거이지 서로 다른 인과·심리 메커니즘의 증명은 아니다.

## 측정동일성 해석

| 단계 | CFI | 비교 ΔCFI | 판정 |
|---|---:|---:|---|
| Configural | .950 | — | 확보 |
| Metric | .949 | -.001 | 확보 |
| Scalar | .937 | -.012 | 미확보 |

Metric invariance가 확보되어 공공·민간의 구조경로 비교는 가능하다. Scalar invariance는 ΔCFI 기준 .01을 근소하게 넘어서므로 잠재평균 차이는 본문에서 확정적으로 해석하면 안 된다. 기존 잠재평균 표는 참고 또는 부록으로만 두어야 한다. 부분 절편동일성은 아직 검토되지 않았다.

- 원자료에는 공공 직급 `SQ2K4`, 민간 직급 `SQ3K3`가 있으나 현재 전처리 자료에 없다. 두 부문의 코딩을 공통척도로 조화시키는 규칙이 없어 추가 통제로 임의 투입하지 않았다.

## 수정 후 권장 보고 기준

1. 주분석은 통제변수 포함 잠재 SEM, H7은 PI 확장 SEM으로 고정한다.
2. 표준화 계수는 β, 비표준화 계수는 B로 표기하고 한 열에서 혼용하지 않는다.
3. 잠재 직접효과·대비·간접효과·상호작용은 BCa 95% CI를 우선 판단 기준으로 삼는다. 새 H3 차이만 계산 제한상 1,000회 percentile임을 별도 명시한다.
4. p와 CI가 충돌하면 CI 기준 판정을 본문에 쓰고 다른 결과도 숨기지 않는다.
5. 각 표에 분석모형, 통제변수, N, 추정기, 표준화 여부, bootstrap 유형·반복 수·시드를 적는다.
6. OLS/PROCESS 결과는 강건성 부록으로 이동하고 SEM과 다른 수치는 추정대상·측정오차 보정 차이로 설명한다.
7. 공공·민간은 경로 차이만 해석하며 잠재평균은 scalar 미확보로 해석하지 않는다.
