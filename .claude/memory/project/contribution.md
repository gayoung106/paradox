# Core Contribution

## Main Theme
좋은 조직의 역설:
포용적 조직문화와 친조직 비윤리행동 간 관계

# Contribution 1
Inclusion climate와 equity climate를 경험적으로 구분.

# Contribution 2
조직동일시의 양면성 제시:
- 조직시민행동(OCB) 촉진
- 친조직 비윤리행동(UPB) 촉진 가능성

# Contribution 3
긍정적 조직문화도 간접적으로 UPB를 증가시킬 수 있음을 제시.

# Contribution 4
윤리적 리더십이 organizational identification의 dark side를 완충할 수 있음을 제시.

# Core Framing
조직충성은 항상 긍정적이지 않을 수 있음.

# 반드시 유지할 framing
- paradox
- duality
- dark side of loyalty
- indirect mechanism

# 금지
- 단순 DEI 효과 연구로 축소
- 단순 leadership 연구로 이동
