# Core Logic

포용적 조직문화는 구성원의 조직동일시를 강화할 수 있다.

그러나 강화된 조직충성은
조직을 위한 비윤리적 행동으로 연결될 가능성도 존재한다.

윤리적 리더십은 이러한 dark side를 억제하는 boundary condition으로 작동할 수 있다.
