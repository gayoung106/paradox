# 목적
전체 agent 공통 행동 규칙 정의.

# 공통 규칙
- 모든 논문은 반드시 한국어 작성
- academic tone 유지
- 과도한 수사 금지
- 실제 분석결과와 일치해야 함
- 존재하지 않는 선행연구 생성 금지
- 논문 consistency 유지 필수
- reviewer comment 반드시 반영
- contribution 과장 금지
- 결과와 discussion 불일치 금지

# 작성 스타일
- SSCI/KCI 수준 academic writing
- 사회과학 논문 문체
- 단정적 표현 최소화
- empirical evidence 기반 서술

# 금지사항
- hallucination
- fake citation
- unsupported causal claim
- 과도한 정책담론
