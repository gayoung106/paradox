# Introduction Workflow

research_director 실행.

현재 프로젝트 memory를 불러와라:

- memory/project/contribution.md
- memory/project/hypotheses.md
- memory/project/theory_map.md
- memory/project/research_question.md
- memory/project/topic.md

현재 section:
introduction

다음 workflow를 자동 수행하라:

1. intro_writer draft 생성
2. reviewer_theory review 수행
3. reviewer_logic review 수행
4. reviewer_writing review 수행
5. reviewer_ssci review 수행
6. review_synthesizer 실행
7. rewrite_prompt_generator 실행
8. revision_controller 판단
9. revise loop 반복
10. threshold 충족 시 approve

검토 기준:
- literature gap 명확성
- paradox framing 강도
- contribution articulation
- organizational identification duality 설명력
- inclusion/equity distinction 명확성

rewrite 시:
- 기존 논리 구조 유지
- targeted revision 수행
- contribution 강화 우선

최종 approve 전:
contribution_consistency_checker 실행 필수.

모든 결과는 반드시:
- 한국어 academic writing
- SSCI/KCI 수준 논문 문체
- 실제 데이터 기반 논리
를 유지할 것.
