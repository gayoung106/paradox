# Reviewer Iteration Workflow

# 목적
논문 section별 iterative review 및 revise workflow 관리.

# 기본 Workflow

1. Writer draft 생성
2. Reviewer routing 수행
3. Reviewer evaluation 수행
4. Review synthesis 수행
5. Revision 필요 여부 판단
6. Rewrite prompt 생성
7. Writer rewrite 수행
8. Re-review 수행
9. Contribution consistency 검증
10. Approve 여부 판단
11. 다음 section 이동

---

# Detailed Workflow

Writer
→ reviewer_router
→ reviewers
→ review_synthesizer
→ revision_controller
→ rewrite_prompt_generator
→ writer rewrite
→ re-review
→ contribution_consistency_checker
→ research_director approval
→ next section

# Review Synthesis Rules

review_synthesizer는:
- reviewer conflict 해결
- critique priority 정렬
- duplicate critique 제거
- rewrite focus 도출

을 수행한다.

---

# Rewrite Rules

rewrite_prompt_generator는:
- targeted revision
- contribution articulation 강화
- 기존 논리 유지
- unnecessary rewrite 방지

를 수행한다.

---

# Approval Conditions

approve 조건:

- overall_score >= threshold
- unresolved major concern 없음
- contribution consistency 확보
- theory-result alignment 유지
- reviewer conflict 해결 완료

---

# Rewrite Conditions

다음 상황에서는 rewrite 수행:

- contribution weak
- logic inconsistency
- methodology flaw
- paradox framing 약화
- section coherence 문제
- reviewer major concern 존재

---

# Iteration Rules

- 최대 revise loop: 3회
- 동일 critique 반복 시 escalation
- quality improvement 없을 시 director intervention

---

# Escalation Rules

다음 상황에서는 research_director 호출:

- reviewer disagreement 지속
- contribution ambiguity 지속
- rewrite quality improvement 없음
- unresolved methodology concern 존재

---

# Contribution Consistency Rules

모든 section approve 전:
contribution_consistency_checker 실행 필수.

특히 다음 consistency 유지:

- paradox framing
- organizational identification duality
- inclusion/equity distinction
- dark side of loyalty

---

# Final Goal

단순 manuscript generation이 아니라:

- SSCI/KCI 수준 논리 엄밀성
- contribution clarity
- methodological rigor
- coherent theoretical framing

을 확보하는 것을 목표로 한다.
