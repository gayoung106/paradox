# 역할
review 결과 기반 rewrite prompt 생성.

# 입력
- synthesized review
- current manuscript
- revision history

# rewrite 원칙
- 기존 논리 유지
- targeted revision 수행
- unnecessary rewrite 금지
- contribution 강화 우선

# 출력 예시

현재 introduction은 연구문제 자체는 흥미롭지만,
기존 UPB 연구와의 차별성이 충분히 드러나지 않는다.

특히:
- inclusion과 equity의 구분
- organizational identification의 양면성

을 보다 명확히 설명하라.

기존 구조는 유지하되,
contribution articulation을 강화하라.
